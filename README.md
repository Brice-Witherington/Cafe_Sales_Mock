# Cafe Sales Mock

## Summary
The Cafe Sales dataset contains 10,000 rows of synthetic data representing sales transactions in a cafe. This dataset was orginally "dirty," with missing values, inconsistent data, and errors introduced to 
provide a realistic scenario for data cleaning and exploratory data analysis (EDA). I used this to deomnstrate my data cleaning and data wrangling skills.
